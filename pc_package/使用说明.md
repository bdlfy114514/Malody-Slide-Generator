# Malody Slide 生成器 —— PC 版 1.2

一个给音游 Malody 用的 Slide（滑条）曲线生成工具。填几个关键节点，自动算出平滑的
细分折线段并写进 `.mc` 谱面文件。

---

## 一、先确认电脑上有 Python

按 `Win + R`，输入 `cmd` 回车，然后输入：

```bat
python --version
```

- 显示出 `Python 3.8.0` 或更高 → 可以了，看第二步。
- 提示"不是内部或外部命令" → 先装 Python：
  1. 打开 <https://www.python.org/downloads/> 下载最新版；
  2. **安装时务必勾选最下面的 `Add Python to PATH`**（忘了会一直报错）；
  3. 装完后**重新打开** cmd，再执行一次 `python --version` 确认。

> macOS / Linux 一般自带 Python 3。Linux 上若报 `No module named tkinter`，
> 执行 `sudo apt install python3-tk`。
> 本工具只用 Python 标准库，**不需要 pip 装任何东西**。

---

## 二、运行

**Windows**：直接双击 **`run.bat`**（如果没反应，就双击 `start.bat`，两者作用相同）。

如果闪一下就消失、或者你想看报错信息，就在这个文件夹里打开终端手动运行：

```bat
python slide_generator_v1_2.py
```

**macOS / Linux**：

```bash
python3 slide_generator_v1_2.py
```

> ⚠️ `slide_generator_v1_2.py` 和 `slide_core.py` **必须放在同一个文件夹里**，
> 不要只把主程序单独拎出去。

---

## 三、使用

1. 点 **📂 选择谱面文件**，在弹出的系统文件对话框里选中你的 `.mc` 谱面。
   - **不选也可以**：此时只预览、不写文件，适合反复调形状。
2. 填 **节点**：「时间」填 `[拍,线,细分]`，「位置」填 `0–256`。
3. 每个节点下方选 **形状**，需要锯齿就勾上 **锯齿**。
4. 填 **节点密度**、**宽度 w**；只要有任意一段勾了锯齿，就必须填 **锯齿幅度**。
5. 点 **生成 Slide 并写入谱面**（或按 `Ctrl+Enter`）。

### 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl + O` | 选择谱面文件 |
| `Ctrl + N` | 添加节点 |
| `Ctrl + Enter` | 生成并写入 |

## 四、参数怎么填

### 时间 `[a, b, c]`

| 字段 | 含义 |
|---|---|
| `a` | **绝对拍数**（从 0 拍开始算） |
| `b` | 当前拍内的**第 b 条节拍线**（正拍点处为第 0 条） |
| `c` | 当前拍被**均匀分成 c 份** |

例：`[4, 1, 4]` = 第 4 拍、分成 4 份、取第 1 条线。

> ⚠️ 制谱器里拍数从 1 开始标，谱面文件里从 **0** 开始，
> 所以填 `a` 时要用**制谱器显示的拍数减 1**。

### 位置 `0 – 256`

`0` = 最左，`128` = 正中，`256` = 最右。

### 其它

| 参数 | 说明 |
|---|---|
| **节点密度** | 正整数。越大越细越平滑，文件也越大。想要 "`1/8`"（32 分音符）的间隔就填 `8`。 |
| **宽度 w** | Slide 在游戏里的显示宽度，`256` 为全宽。 |
| **锯齿幅度** | 整数（可正可负可为 0），所有锯齿段共用。常见取值 3–15。 |

### 形状

每两个相邻节点之间为一段，**段数 = 节点数 − 1**：

| 代号 | 名称 | 效果 |
|---|---|---|
| `s` | 直线 | 匀速 |
| `si` | 先快后慢 | 出发快，接近节点时减速卡点 |
| `so` | 先慢后快 | 出发慢，随后加速冲出 |
| `b` | S 形 | 两头慢中间快 |

### 锯齿的含义

勾了锯齿的段，其**段内偶数序号的 seg**（第 1、3、5… 个）会被抬高「锯齿幅度」。
**每段从自己的起点重新计数**，所以相邻的锯齿段互不影响，没勾的段保持完全平滑。

## 五、写入行为（重要）

- 写入的是**你选中的那个文件本身**（原地修改），不会另存。
- 写入前自动备份为 `你的谱面.mc.bak`；该备份已存在时会顺延为 `.mc.bak.1`、`.mc.bak.2`…
  **永远不会覆盖你之前的备份**。
- 只在首个 `"note":[` 之后插入生成的 Slide，**不动文件里其它任何内容**。
- 找不到 `"note":[` 标记时会**报错并中止**，绝不改动文件。

## 六、常见问题

**Q：双击 run.bat / start.bat 闪一下就没了？**
说明脚本报错了。在本文件夹打开 cmd，执行 `python slide_generator_v1_2.py`，
错误信息就会留在窗口里。最常见原因是没装 Python，或安装时没勾 `Add Python to PATH`。

**Q：提示找不到 `slide_core.py`？**
它必须和 `slide_generator_v1_2.py` 放在同一个文件夹里。

**Q：写了但游戏里没变化？**
确认选对了 `.mc` 文件，并且在制谱器里重新加载了谱面。
原文件可随时用同名 `.bak` 备份还原。

**Q：`.bak` 会覆盖我上一个备份吗？**
不会，会顺延编号。
