# Malody Slide 生成器

一个为 Malody 谱面设计的高效 Slide（滑条）曲线平滑插值工具（本工具完全使用`vibe coding`生成，人类编写的程序含量为0，甚至连这篇`README.md`也是AI生成的）。用户只需输入关键控制点和缓动形状，工具即可自动计算并批量生成平滑的细分折线段（Seg），并支持安全写入谱面文件与实时画面预览。

---

## 核心功能
* **缺省输入**：最多支持 5 个节点，最少仅需输入 2 个节点即可生成。
* **图形预览**：点击生成后，右侧画布会以音游视角（底部为起点，顶部为终点）直观展示 Slide 的弯曲形状。
* **安全备份**：写入谱面时自动在同目录下生成 `.mc.bak` 备份文件，绝不覆盖或损坏原谱面内容。
* **路径兼容**：自动识别并去除因操作系统的“复制路径”功能而附带的单双引号。

## 参数填写指南

为了让生成结果完全符合预期，请严格按照以下规则填写参数：

### 1. 时间格式：`[a, b, c]`
由于音游中通常使用节拍定位，本工具的时间必须填写为由 3 个整数组成的列表：
* **`a`**：目标所处的**绝对拍数**（从 0 拍开始算）。
* **`b`**：当前拍内的**第 b 条节拍线**（正拍点处为第 0 条）。
* **`c`**：当前拍被**均匀分成了 c 份**（节拍细分数）。
* *示例*：`[4, 1, 4]` 代表第 4 拍，且这一拍被平分成了 4 份（即 16 分间隔），当前位置在第 1 条线（即第 4 拍的第一条红色线）。  
* *这里要注意一下，制谱器内是从 1 开始标拍数的，但谱面文件内实际从第 0 拍开始，因此填写a值时，数值是制谱器内标注拍数减去1。

### 2. 位置（X 坐标）：`0 - 256`
代表 Slide 在屏幕上的绝对横向位置：
* **`0`**：屏幕的最左侧。
* **`256`**：屏幕的最右侧。
* **`128`**：屏幕的正中间。

### 3. 其它参数
* **节点密度 (Density)**：一个正整数。数值越大，Slide 被切分得越细、越平滑，但同时谱面文件体积也会变大。例如，如果希望在制谱器里节点间隔表现为“`1/8`”，也就是32分音符，将节点密度设置为`8`即可
* **宽度 (w)**：Slide 在游戏里的显示宽度，单位与X坐标相同，`256`表示全宽。

### 4. 形状类型 (Shape)
工具支持 4 种经典的音游缓动轨迹，数量必须**恰好比你输入的控制节点数量少一个**，生成器将依次按照输入的类型在节点间生成slide：
* **`s` (Straight)**：直线，均匀匀速地从上一个点过渡到下一个点。
* **`si` (Sine In)**：正弦缓动（先快后慢），刚出发时速度极快，在接近下一个节点时减速平滑卡点。
* **`so` (Sine Out)**：反余弦缓动（先慢后快），刚出发时非常缓慢，随后逐渐加速冲向下一个节点。
* **`b` (Bezier)**：半周期正弦缓动（慢-快-慢），两头慢中间快，俗称 S 形曲线。

## 基本使用方法

1. **运行程序**：如果电脑已安装 Python3 环境，直接运行 `slide_generator.py` 脚本打开 GUI 窗口；若没有，可运行`slide_generator.exe`。
2. **（选填）填写谱面路径**：
   * 在最上方框内粘贴你的 Malody 谱面文件（`.mc` 格式）的路径。
   * **注意**：如果留空不填，工具将**只在右侧显示形状预览**，不会修改任何文件。适合反复调试形状。
3. **输入节点与参数**：
   * 在“节点1”和“节点2”中分别输入起始和终点的时间与位置（如需要实现更复杂的slide形状，可继续往下填写节点3、4、5）。
   * 填写节点密度（推荐 `8` 或 `16`）、宽度以及对应的形状简写（`s` / `si` / `so` / `b`）。
4. **生成与导入**：
   * 点击下方 **[生成并预览]** 按钮。
   * 右侧画布将立刻刷新并绘制出 Slide 轨迹。如果填写了谱面路径，提示框会确认已成功写入谱面。
