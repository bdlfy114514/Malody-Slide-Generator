Malody Slide 生成器 · 使用说明

安卓版　|　一个用于音乐游戏 Malody 的 Slide（滑条）曲线平滑插值工具

⚠️ 版本提示：本工具面向 Malody 4.3.7 版本编写。 谱面的时间、坐标等格式以该版本为准；其它版本的谱面格式若不同，生成结果可能无法被正确识别。请尽量使用 4.3.7 制谱与游玩。

📥 安装

  1. 把 SlideGenerator_v1.1.apk 传到手机（数据线拷贝、聊天工具发送等均可）。
  2. 点击安装。若系统提示“未知来源应用”，请在手机设置中允许该来源安装。
  3. 安装要求：Android 7.0 及以上，且手机为 64 位（2015 年后的绝大多数手机都满足）。

📂 谱面文件放在哪里（很重要，请先看这条）

游戏的谱面文件存放在手机根目录下的：

/data/malody/beatmap

注意：是手机根目录里的 data，不是 Android/data！ 这两个是完全不同的文件夹，请务必找对：

✅ 正确：内部存储根目录 → data → malody → beatmap
❌ 错误：内部存储 → Android → data（这里是 App 的私有数据，不是游戏谱面）

在手机自带文件管理器里，一般这样找：打开“文件管理” → 进入“内部存储 / 手机存储”（根目录，不是 Android 文件夹） → 找到 data 文件夹 → malody → beatmap，你的谱面（.mc 文件）就在这里。

小提示：部分文件管理器默认隐藏根目录下的 data，如找不到，可在文件管理器的设置里打开“显示隐藏文件 / 文件夹”。

✨ 核心功能

  • 可视化选谱：点击 [📁 选择谱面文件] 按钮，直接调起手机的文件管理器，在弹出的界面里点到 /data/malody/beatmap 选中你的 .mc 谱面即可，无需手动输入任何路径。
  • 节点编辑：节点可在 2–15 个之间自由增删，最少 2 个即可生成。
  • 图形预览：点击生成后，上方的预览画布会以音游视角（底部为起点，顶部为终点）直观展示 Slide 的弯曲形状（含锯齿）。
  • 分段锯齿：两个节点之间的每一段 Slide 都能单独选择是否加锯齿，不再只能整条全局加锯齿。
  • 安全写回：写入谱面时会直接写回你选择的那份谱面文件（原目录、原文件），并在写入前自动生成 原名.bak 备份，绝不损坏原谱面内容。

🚀 基本使用方法

  1. 打开 App：点击桌面上的「Slide 生成器」图标。
    （首次启动可能会有几秒白屏，那是在解包内置的 Python 运行环境，稍等即可，之后启动会很快。）
  2. （选填）选择谱面文件：点击 [📁 选择谱面文件]，在系统文件管理器里进入根目录 /data/malody/beatmap，选中你的 .mc 谱面文件。
    • 注意：如果不选文件，工具将只在上方显示形状预览，不会修改任何文件，适合反复调试形状。
  3. 输入节点与参数：在「节点 1」「节点 2」里填写起始与终点的时间、位置；需要更多节点时点 「＋ 添加节点」（最多 15 个），点节点右上角的「删除」可移除。每一段（相邻两个节点之间）都可以单独选择形状和是否加锯齿。再填写节点密度（推荐 8 或 16）与宽度。
  4. 生成与导入：点击底部 「生成 Slide」 按钮。上方画布会立刻刷新并绘制出轨迹（含锯齿）；如果已选择谱面文件，界面会提示已成功写入，并告知备份文件名。

📝 参数填写指南

为了让生成结果完全符合预期，请严格按照以下规则填写参数。

1. 时间格式：[a, b, c]

由于音游中通常使用节拍定位，本工具的时间必须填写为由 3 个整数组成的列表：

  • a：目标所处的绝对拍数（从 0 拍开始算）。
  • b：当前拍内的第 b 条节拍线（正拍点处为第 0 条）。
  • c：当前拍被均匀分成了 c 份（节拍细分数）。

示例：[4, 1, 4] 代表第 4 拍，且这一拍被平分成了 4 份（即 16 分间隔），当前位置在第 1 条线（即第 4 拍的第一条红色线）。

注意：制谱器内是从 1 开始标拍数的，但谱面文件内实际从第 0 拍开始，因此填写 a 值时，数值应为制谱器内标注的拍数减去 1。

2. 位置（X 坐标）：0 – 256

代表 Slide 在屏幕上的绝对横向位置：

  • 0：屏幕的最左侧。
  • 256：屏幕的最右侧。
  • 128：屏幕的正中间。

3. 其它参数

  • 节点密度 (Density)：一个正整数。数值越大，Slide 被切分得越细、越平滑，但同时谱面文件体积也会变大。例如，如果希望在制谱器里节点间隔表现为“1/8”，也就是 32 分音符，将节点密度设置为 8 即可。
  • 宽度 (w)：Slide 在游戏里的显示宽度，单位与 X 坐标相同，256 表示全宽。

4. 形状类型 (Shape)

每一段（相邻两个节点之间）都可以单独选择形状，在节点卡片里用下拉框选择即可（界面直接显示中文名）。工具支持 4 种经典的音游缓动轨迹：

界面名称含义
直线均匀匀速地从上一个点过渡到下一个点。
先快后慢刚出发时速度极快，在接近下一个节点时减速平滑卡点。
先慢后快刚出发时非常缓慢，随后逐渐加速冲向下一个节点。
S 形半周期正弦缓动（慢-快-慢），两头慢中间快。

5. 分段锯齿（可选）

在任意一段的右侧勾选 「锯齿」，即可只给这一段加上锯齿（来回摆动）的效果，其余没勾选的段保持平滑。只要任意一段勾了锯齿，就需要在「其他参数」里填写锯齿幅度（一个整数，可正可负可为 0）——该幅度由所有锯齿段共用。

小技巧：点节点区右上角的「全开锯齿」/「全关锯齿」可以一次性勾选或取消所有段。

❓ 常见问题

Q：找不到 /data/malody/beatmap 文件夹？
A：确认你进的是内部存储的根目录，而不是 Android/data。根目录下应有 data 文件夹；若看不到，请在文件管理器设置里打开“显示隐藏文件”。

Q：生成的 .bak 备份在哪里？
A：正常情况下和谱面文件在同一个目录。但安卓系统不允许 App 在「下载」这类系统目录里新建文件，如果你的谱面恰好放在那里，备份会自动存到系统的「下载」目录，界面会给出提示。无论哪种情况，都会先完成备份再改写原文件。

Q：我的手机装不上？
A：本 App 只提供 64 位版本，极老的 32 位手机无法安装；系统需为 Android 7.0 及以上。

Q：会不会把我的谱面弄坏？
A：写入是“插入”式操作（在 "note":[ 之后插入生成的内容），并且写入前一定先生成备份，不会覆盖其它已有内容。为稳妥起见，建议保留 .bak 备份文件。
